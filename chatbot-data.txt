Q: MCP? | Model Context Protocol | Internal RAG platform | Code search | Codebase
A: The internal RAG platform is built on the company's indexed codebase: the code is converted into documents, and every question runs a double search, on the documents and on the code. The same procedure can be called through a Model Context Protocol (MCP) server and its tools. Answers adapt to the person asking (a consultant gets a different answer from a developer, and not everyone is shown the code) and to the type of request, such as an impact analysis or documentation.
